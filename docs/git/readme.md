# Learning Git Resources

## References

[git (kovacinacomputing.com)](https://kovacinacomputing.com)

This is a slide deck that I put together for one of the classes I taught. Very high level, as it was intended as a presentation aid for me, not a handout. But it's not a bad place to start in terms of vocabulary.

Also, note that this is a non-linear slide deck. If using the arrow keys to navigate, there are some slides that have other slides "underneath" and not just to the right. If you hit the '?' it will show you the keyboard shortcuts for navigation.

[Git Tutorial (w3schools.com)](https://www.w3schools.com/git/)

You will find that many tutorials conflate Git and GitHub. This one does a very nice job of separating them. I'd suggest going through just the Git portion. In general, W3CShools is an excellent learning resource for "programmery" type things.

[Git - gittutorial Documentation (git-scm.com)](https://git-scm.com/docs/gittutorial)

This is the authoritative documentation for Git. Not the best in terms of tutorials or learning, but when in doubt, this is where to go.

## Learning Git Interactive Tutorials

[learngitbranching.js.org](https://learngitbranching.js.org/)

As the title says, you'll learn about Git branching. It's a good topic to understand at a basic level. We have no desire to go full-ninja in terms of git branching here at Orbital.

[gitimmersion.com](https://gitimmersion.com/index.html)

I wish I had something like this many years ago. A hold-your-hand tutorial that is pretty close to real-life with Git. The only issue is they expect you to install Ruby (just for the project). Feel free to read this and not necessarily execute it all.
